Privacy Policy

Baidu Pan Agent Connector (Unofficial)
Effective date: 2026-08-07 · Last updated: 2026-08-07

This extension is an unofficial capability connector. It does not provide an autonomous product experience by itself. A companion local Agent (and optional Skills) decides which operations to request; the extension executes them only in your browser session on Baidu Netdisk (pan.baidu.com).

This extension is not affiliated with, endorsed by, or sponsored by Baidu.

1. Data the extension accesses

When you use the extension on a page where you are logged into Baidu Netdisk, it may read from that page context only what is needed to call Baidu’s same-origin web APIs for file listing and file-management operations (for example directory paths, file names, sizes, and temporary page tokens such as bdstoken). Those tokens are used in-memory for API requests and are not intentionally persisted by the extension as account credentials.

Task packs (JSON describing mkdir / move / rename / copy / delete-style operations) may be stored in chrome.storage.local on your device so the UI and background worker can track progress.

2. Local bridge communication

The extension may poll a local-only HTTP service on http://127.0.0.1:27865 or http://localhost:27865 (the default companion task bridge run by your Agent toolchain). Communication is intended to stay on your machine. The extension does not phone home to the developer’s servers.

If no local bridge is running, the connector simply cannot receive Agent-issued tasks over that channel.

3. What we do not collect

  • No developer-operated analytics, advertising, or telemetry backend.
  • No sale of user data.
  • No intentional transmission of Baidu cookies or account passwords to third parties by this extension.
  • No remote code download for execution.

4. How data is used

Data is used solely to provide the extension’s single purpose: connect a local Agent to Baidu Netdisk so authorized task packs can be executed in your logged-in browser session, and to show local status in the popup/panel.

Deleting tasks in the UI clears local pack state. Baidu Netdisk “delete” operations (if requested by a task pack) follow Baidu’s own recycle-bin behavior; they are not performed by the developer remotely.

5. Third parties

Network requests go to:

  • https://pan.baidu.com/* — Baidu Netdisk, under your existing login and Baidu’s terms;
  • http://127.0.0.1:27865/* and http://localhost:27865/* — your local Agent bridge only.

Baidu’s handling of account and file data is governed by Baidu’s own privacy policy and terms of service. This document only covers the extension’s behavior.

6. Permissions (plain language)

  • storage — save task packs and UI state on device.
  • activeTab — interact with the tab you open for Netdisk / popup actions.
  • Host: pan.baidu.com — run the content script and call same-origin Netdisk APIs while you are logged in.
  • Host: 127.0.0.1 / localhost:27865 — receive task packs and report results from/to the local Agent bridge.

7. Children

This tool is intended for adult power users and developers integrating Agents. It is not directed at children.

8. Changes

Material changes to this policy will be reflected by updating the “Last updated” date on this page and, where required, the Chrome Web Store listing.

9. Contact
